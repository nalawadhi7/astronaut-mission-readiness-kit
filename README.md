# 🧑‍🚀 Astronaut Mission Readiness Kit

> Clear, step-by-step checklists that help astronauts stay safe and organised
> from launch day to life aboard the International Space Station.

## 🌍 Project Idea
Life in space runs on procedures. One missed step during a launch, a spacewalk,
or an emergency can put a crew in danger. The Mission Readiness Kit collects the
most important astronaut procedures into simple, easy-to-follow checklists that
can be ticked off one item at a time.

## 🚀 How It Helps NASA
- **Safety:** emergency procedures are quick to find and easy to follow under pressure.
- **Training:** astronaut candidates and students can study real-style procedures.
- **Organisation:** all mission checklists live in one shared, version-controlled place,
  so updates are tracked and reviewed before they are approved.

## 🧰 Technologies / Tools Used
- **GitHub** – repository, issues, project board, branches, pull requests
- **Markdown** – checklists using GitHub task-list checkboxes
- **NASA public resources** – reference for ISS procedures

## 📖 How to Use
1. Open this repository on GitHub.
2. Choose a folder:
   - `checklists/` – routine mission procedures
   - `emergencies/` – emergency response procedures
3. Click any file to open its checklist.
4. Follow the steps in order. Each item has a checkbox to track progress.

## 📂 Project Structure
| Folder | Contents |
|---|---|
| `checklists/` | Pre-launch, daily routine, spacewalk prep |
| `emergencies/` | Fire, depressurization, toxic atmosphere |
| `docs/` | Project reflection |

## ⚠️ Disclaimer
This is a student educational project. Procedures are simplified and are not official NASA documents.
